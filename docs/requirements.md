# Requirements — Kurma Travel

## 1. Functional Requirements

### FR-01 — Melihat Profil Perusahaan
Pengguna dapat melihat informasi mengenai Kurma Travel.

### FR-02 — Melihat Paket
Pengguna dapat melihat daftar paket Umroh dan Haji.

### FR-03 — Melihat Detail Paket
Pengguna dapat melihat harga, durasi, hotel, keberangkatan, dan fasilitas paket.

### FR-04 — Melihat Galeri
Pengguna dapat melihat foto kegiatan Kurma Travel.

### FR-05 — Membaca Artikel
Pengguna dapat membaca artikel yang tersedia.

### FR-06 — Menghubungi Kurma Travel
Pengguna dapat mengirim pesan melalui halaman kontak atau WhatsApp.

### FR-07 — Mengelola Konten
Admin dapat mengelola paket, fasilitas, galeri, dan artikel.

## 2. Non-Functional Requirements

### NFR-01 — Responsive
Website dapat digunakan pada desktop dan perangkat mobile.

### NFR-02 — Performance
Halaman website dapat dimuat dengan waktu yang wajar.

### NFR-03 — Usability
Tampilan mudah dipahami oleh pengguna.

### NFR-04 — Maintainability
Kode dibuat dengan struktur yang terpisah antara frontend, backend, dan database.
